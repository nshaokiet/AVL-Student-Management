ACTUAL TREE METRICS

AVL tree Worst-case search O(log n)

Ordinary BST Worst-case search O(n)

Orange marks the actual search path; green marks a found key. AVL restores balance after insertion, keeping height O(log n). An ordinary BST performs no rotations: sorted insertion can create a chain of height n. Node heights and balance factors are calculated for both trees; the ordinary BST can remain unbalanced.

AVL complexity reference

Search O(log n)Insertion O(log n)Deletion O(log n)Single rotation O(1)Traversal O(n)Storage O(n)

These are core AVL bounds. Full snapshots, tree cloning, SVG rendering and JSON persistence add separate overhead. Capacity: 250 students. Comparison: at most 50 IDs.
